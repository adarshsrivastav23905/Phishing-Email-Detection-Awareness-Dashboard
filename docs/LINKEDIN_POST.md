# LinkedIn Post Summary

I’m excited to share my cybersecurity project: Phishing Email Detection & Awareness Dashboard.

This project is a defensive, beginner-friendly security dashboard that analyzes suspicious emails using sender, subject, body, URL, and attachment indicators. It combines rule-based phishing detection, explainable risk scoring, synthetic dataset generation, and awareness education in one practical Streamlit application.

Key highlights:
- Phishing and social-engineering indicator analysis
- URL, sender, and attachment risk checks
- Explainable classification and recommendations
- Secure, ethical, synthetic-only dataset design
- Dashboard analytics and history tracking
- Portfolio-ready project for cybersecurity learning

This project helped me strengthen my understanding of email security, threat analysis, explainability in security systems, and how cybersecurity teams evaluate suspicious communication patterns.
